# 部署验证记录

验证日期：2026-11-08。

## pip 安装

使用独立 Python 3.11 环境构建 wheel，从完整锁定清单以 `pip install --no-deps -r requirements.txt` 安装依赖，再通过 `pip install --no-deps <wheel>` 安装应用。从仓库外调用 `video-studio`，使用独立数据目录和测试端口。

通过项：API 健康、UI 健康、静态资源、FFmpeg 自动检测、引擎就绪、内置资源完整性哈希、真实断网视频合成。离线引擎三项测试全部通过。pip check 仅报告已记录的 MoviePy/Pillow 元数据上限冲突。

## Docker

使用 Python 3.11 slim、Linux amd64 构建。Docker Hub 拉取超时，使用 `PYTHON_IMAGE=public.ecr.aws/docker/library/python:3.11-slim` 构建成功。通过 Compose 启动独立测试实例，映射宿主机 4380 到容器 4180。

通过项：API 与 UI 健康、Compose healthy 状态、FFmpeg、引擎就绪、持久化卷重启保留测试凭据。容器内资源完整性、依赖兼容性及真实断网合成三项测试全部通过。容器以非 root 用户运行。

## 回归与边界

API 既有回归测试 47 项通过，Compose 配置与修改的 Python 语法检查通过。使用、部署手册及项目 README 已检查指定名称不存在；第三方许可与来源声明保留。

未调用真实收费模型、在线配音或素材平台；这些功能仍需用户配置有效凭据及网络。本轮没有验证 Windows、Linux arm64 或 GitHub 发布流程。当前交付为源码与本地构建配置，未发布公共包和镜像。
